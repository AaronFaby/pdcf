Two controllers. No hardware required.

How to use the simulator

1. Click Connect P1 (and Connect P2 for two players). Wait for CONTROLLER READY.

2. Choose Local mode for two players, then Featured bout. After a screen change, click Release P1/P2 and wait for CONTROLLER READY.

3. Controller buttons toggle between held and released. A dark button is held. Click it again or use Release to let go. Combine directions, guard and attacks.

By default A jumps / confirms; X punches; Y kicks; B uses special / goes back. Remap gameplay buttons in Options → Controls; menu A/B/Start stay fixed. Start starts or pauses a match. Disconnect either controller to test recovery.

This page exercises the game’s real controller input code using virtual devices. It does not validate hardware pairing, physical button layouts or real input latency. Focus-loss pausing is suppressed inside this simulator so its outer buttons remain usable.
