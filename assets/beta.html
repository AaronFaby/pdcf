This desktop beta includes six fighters, four animated stages, Arcade, Training, single CPU matches and local two-player. Keyboard play is the baseline; standard controllers are included for beta testing. Match balance and device coverage are still developing.

Testing coverage

Automated checks cover combat, all six CPU personalities, Arcade progression, guided lessons, keyboard and virtual-controller input, loading and audio recovery, saved settings, display options and fullscreen. Hosted release checks run Chromium, Firefox, WebKit, Chrome and Edge. A beta tag is published only after the release candidate’s checks pass.

Separate local endurance sessions have completed real-time Arcade ladders, CPU and local rematches, and two-minute Training sessions with pauses, nested menus and reconnects. These observe native audio cleanup, bounded runtime state and frame timing. Automated bots are separate from human balance testing; virtual controllers are separate from physical hardware. See the repository’s verification record for build-specific evidence and limits.

Known limitations

  • Combat balance and difficulty: provisional. Seeded CPU results do not establish human matchup balance or a measured learning curve.
  • Physical controllers: pairing, latency, real button labels and device-specific reconnect behavior need hands-on verification. Standard mappings are required; identical controllers with changed indexes may need the existing P1/P2 Swap action.
  • Audio listening: the original synthesized music and Foley have automated playback/cleanup checks; speaker and headphone listening still need review. A browser gesture or Enable audio may be required.
  • Safari and hardware: automated WebKit is not the native Safari application. Lower-end machines and high-refresh displays need additional testing. Measured frame timings are not a performance guarantee on other devices.
  • Mobile and touch: this release targets desktop. Touch controls omit throw and dash, and physical touch devices remain unverified.
  • Multiplayer: local play shares a device. Online multiplayer is unavailable; some keyboards cannot register many simultaneous keys.
  • Saves: Arcade progress and preferences stay in one browser/device. There is no account or cloud sync, and clearing site data removes saves. Blocked storage limits persistence.
  • Accessibility: menus, readable HUD, remapping and motion options are available, but the real-time Canvas game is not fully screen-reader playable or formally accessibility-certified.
  • Independent reviews: artwork/branding clearance and hosting privacy configuration remain open review items. Existing character-version, independence and privacy notices continue to apply.

Report a bug or share feedback

Open GitHub Issues →

For a bug, please include:

  1. The build number from the bottom of the game page.
  2. Your browser/version, operating system, and keyboard or controller model.
  3. Mode, difficulty, both fighters and stage.
  4. Steps to reproduce, what you expected, and what happened. Include whether it repeats; a screenshot or short recording can help.

For playtest feedback, describe tutorial clarity, attack readability, counterplay, difficulty progression and which matchups stayed enjoyable.

Issues are public, and posting requires a GitHub account. Do not post private information. Feedback is submitted manually through GitHub; the game does not automatically upload matches, inputs, diagnostic reports or personal information. No public contact email is listed.
